# منصة الجاهزية والمعياري التفاعلية (CS Standardized & ETEC Jaheziya Exam Platform)

منصة تدريب تفاعلية حديثة وشاملة لطلاب علوم الحاسب (جامعة أم القرى - الاختبار المعياري 471 واختبار الجاهزية الوطني ETEC).

---

## 🌟 مميزات المنصة

1. **تغطية شاملة بنسبة 100%:**
   - 108 بطاقات أسئلة رئيسية تغطي كافة الأسئلة الـ 130 (90 جاهزية + 40 معياري مع دمج الـ 22 سؤالاً المشترك).
   - تقسيم المنهج إلى 8 فصول تطابق المعايير الوطنية ونسب الأوزان بدقة.

2. **شريط جانبي متطابق مع التصميم المطلوب:**
   - أرقام الفصول الدائرية (1 إلى 8).
   - نسب الإنجاز التفاعلية الحية (`100%`, `0%` وتحديث ديناميكي فوري).
   - تمييز الفصل النشط بإطار ملون ولون مخصص لكل مادة.
   - قائمة الموضوعات الفرعية مع علامات الصح الخضراء `✓` عند إتمام المذاكرة.

3. **محرك اختبارات تفاعلي حي:**
   - اختيار الإجابات والنقر على **Check Answer**.
   - تلوين الإجابة الصحيحة **بالأخضر (`#10b981`)** مع علامة `✓ Correct Answer`.
   - تلوين إجابة الطالب الخاطئة **بالأحمر (`#ef4444`)** مع إضاءة الإجابة الصحيحة تلقائياً.
   - كشف فوري للشرح باللغة الإنجليزية متضمناً:
     - **Rationale:** السبب العلمي الدقيق.
     - **Distractor Breakdown:** تفنيد الخيارات الخاطئة ولماذا تم استبعادها.
     - **Exam Rule:** القاعدة الذهبية أو القانون للاختبار.

4. **رسوم بيانية وتوضيحية فيكتور (SVG):**
   - رسوم أصلية مدمجة بالكامل لجميع الفصول الـ 8 (AVL Rotations, De Morgan & Venn, Compiler Pipeline, Rational Agent, OS 5-State, Memory Hierarchy & AMAT, ANSI/SPARC 3-Level, OSI 7 Layers).

5. **حفظ التقدم التلقائي (LocalStorage):**
   - حفظ إجابات الطالب، نتائجه، الأسئلة المفضلة، والموضوعات المقروءة حتى بعد إغلاق المتصفح أو إعادة التحميل.

## 🚀 طريقة الرفع المباشر على Vercel (خلال ثوانٍ)

### الطريقة الأولى: عبر Vercel CLI (مباشرة من جهازك)
افتح موجه الأوامر (PowerShell أو Terminal) داخل المجلد ونفذ:
```bash
cd "c:\جامعة\السنة الاخيرة\اختبار الجاهزية\منصة_الجاهزية"
npx vercel
```
ثم اضغط `Enter` للموافقة على الإعدادات الافتراضية، وسيعطيك Vercel رابطاً عاماً فورياً للمنصة (مثل `https://jaheziya-cs-platform.vercel.app`) لترسله لكامل طلاب الكلية!

### الطريقة الأولى: عبر GitHub & Vercel Dashboard
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. ادخل على [vercel.com](https://vercel.com) واضغط **Add New Project**.
3. اختر المستودع واضغط **Deploy**.
